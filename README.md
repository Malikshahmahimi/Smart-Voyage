# 🌍 Smart Voyage

> **AI-powered travel planning made simple.**
>
> Smart Voyage helps travelers discover destinations, build personalized itineraries, and plan unforgettable trips through an intuitive and modern web experience.

🌐 **Live Website:** https://smartvoyage.in

---

## ✨ Overview

Planning a trip often requires switching between multiple websites for destinations, itineraries, weather, and travel information. Smart Voyage brings everything together into one intelligent platform, making travel planning faster, easier, and more personalized.

Whether you're planning a weekend getaway or a long vacation, Smart Voyage helps you organize your journey with ease.

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/<your-username>/smart-voyage.git
```

Go to the project directory:

```bash
cd smart-voyage
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser:

```
http://localhost:3000
```
